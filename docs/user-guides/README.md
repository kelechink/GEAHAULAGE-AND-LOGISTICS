# User guides

Short guides for each role, used for staff training before go-live. Sign in at `https://geahaulageandlogistics.com/admin` with the email and password FigureWeb gives you. You only see the menus your role allows.

## Two-factor sign-in (everyone)

The first time you sign in, you set up an authenticator app (Google Authenticator, Microsoft Authenticator or similar, free):

1. Install the app on your phone.
2. Scan the QR code on screen, then type the 6-digit code the app shows.
3. Save the 8 **recovery codes** shown next. Each lets you in once if you lose your phone.

After that, each time you sign in you type the current code from the app. Lost your phone and your recovery codes? Ask the administrator to reset two-factor for you. Manage it any time from your avatar menu → **Two-factor sign-in**.
