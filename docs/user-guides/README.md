# User guides

Short guides for each role, used for staff training before go-live. Sign in at `https://geahaulageandlogistics.com/admin` with the email and password FigureWeb gives you. You only see the menus your role allows.

| Guide | For |
|---|---|
| [Management](management.md) | Managing director and senior managers |
| [Operations](operations.md) | Dispatch and operations officers |
| [Sales](sales.md) | Sales and customer service |
| [Finance](finance.md) | Accounts |
| [Drivers](drivers.md) | Drivers with the GEA Driver app |
| [Administrator](administrator.md) | FigureWeb (Super Admin) |

Word versions are in `docs/word/`. Rebuild them after editing with `docs/build-word.sh`.
